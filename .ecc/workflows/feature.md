# Dealer Feature Workflow
1. PLAN: acceptance criteria and affected files.
2. ARCHITECT: check package/database boundaries.
3. IMPLEMENT: smallest appropriate backend/frontend/database/AI/Telegram change.
4. TEST: add/update tests.
5. REVIEW: build, tests, code review.
6. SECURITY: secrets, dependencies, auth/input, AI and webhook attack surfaces.
7. VERIFY: acceptance criteria and known limitations.
8. COMMIT: focused commit; no secrets or unrelated changes.
